Comment installer un skill

Claude Code : lance la commande affichée dans le terminal (les commandes /plugin se tapent directement dans Claude Code). Sinon, copie le dossier du skill dans ~/.claude/skills/.

Claude (appli / site) : télécharge le dossier du skill en .zip depuis GitHub, puis ajoute-le dans Réglages → Capacités → Skills.

Prudence : un skill peut lancer du code. Préfère les skills officiels ou très suivis, et jette un œil au SKILL.md avant d'installer.

Notes : avis éditorial sur l'utilité réelle, la qualité, le suivi et la popularité (novembre 2026).
